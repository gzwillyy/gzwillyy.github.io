Docker Host 网络

网络命名空间

Linux 的 Namespace（命名空间）技术是一种隔离技术，常用的 Namespace 有 user namespace, process namespace, network namespace等

在 Docker 容器中，不同的容器通过 Network namespace 进行了隔离，也就是不同的容器有各自的IP地址，路由表等，互不影响。

Note：准备一台Linux机器，这一节会用到一个叫 brtcl 的命令，这个命令需要安装，如果是Ubuntu的系统，可以通过 apt-get install bridge-utils 安装；如果是Centos系统，可以通过 sudo yum install bridge-utils 来安装
