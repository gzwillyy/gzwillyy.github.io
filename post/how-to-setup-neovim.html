在 Mac 上设置 Neovim

发表于 2025-04-04 分类于 neovim

您可以在此处 https://github.com/josean-dev/dev-environment-files 找到我的配置的源代码。

安装 Nerd 字体

我使用 Meslo Nerd Font 。要安装它，请执行以下操作：

brew tap homebrew/cask-fonts

然后执行以下操作：

brew install font-meslo-lg-nerd-font

然后打开 iTerm2 设置，在 Profiles > Text CMD+, 下将字体更改为 MesloLGS Nerd Font Mono

安装 Neovim

运行：

brew install neovim

安装 Ripgrep

高性能的文本搜索工具，专为快速递归搜索代码库或文本文件而设计

⚡ 极速搜索：比传统 grep 更快，尤其在大型项目中。
🔍 智能默认配置：自动忽略 .gitignore 中的文件（比如临时文件、编译产物等）。
📁 递归搜索：默认直接搜索当前目录及子目录，无需额外参数。
🖥️ 友好的输出：高亮匹配内容，并显示文件名和行号。

brew install ripgrep

# 在当前目录及子目录中搜索关键词 "hello"
rg "hello"
# 在特定目录中搜索（例如 src 文件夹）
rg "functionName" ./src/
# 忽略大小写
rg -i "keyword"
# 仅搜索特定文件类型（如 .py 文件）
rg -tpy "import"

安装 node

brew install node

设置初始文件结构

您的配置将位于 ~/.config/nvim

让我们使用以下命令设置初始文件结构：

创建 nvim 配置目录。

mkdir -p ~/.config/nvim
cd ~/.config/nvim
touch init.lua

创建 lua/gzwillyy/core 目录：

任何时候我使用 gzwillyy，你都可以用你的名字代替它

mkdir -p lua/gzwillyy/core

创建插件目录（将包含所有插件配置/规格）：

mkdir -p lua/gzwillyy/plugins

创建 lazy.lua 文件（将用于设置/配置 lazy.nvim 插件管理器）：

touch lua/gzwillyy/lazy.lua

设置 core 选项

确保您已进入 ~/.config/nvim 并打开配置：

nvim .

导航到 core 文件夹并按下 % 创建一个文件并将其命名为：options.lua

在此文件中添加：

-- Neovim netrw 自带的文件浏览器

-- 设置树状显示
vim.cmd("let g:netrw_liststyle = 3")

-- 隐藏顶部帮助信息
vim.cmd("let g:netrw_banner = 0")

-- 设置窗口宽度为 25%
vim.cmd("let g:netrw_winsize = 25")

设置 lazy.nvim 所有插件

自动安装并配置 lazy.nvim 插件管理器。如果检测到本地没有安装 lazy.nvim，它会通过 Git 克隆官方仓库到 Neovim 的插件目录，并确保其能被正确加载

转到 “lazy.lua” 并将以下内容添加到 bootstrap lazy.nvim

-- 定义 lazy.nvim 的安装路径
-- stdpath("data") 返回 Neovim 的数据目录（通常为 ~/.local/share/nvim）
local lazypath = vim.fn.stdpath("data") .. "/lazy/lazy.nvim"

-- 检查 lazy.nvim 是否已安装（通过检测路径是否存在）
if not vim.loop.fs_stat(lazypath) then
  -- 如果未安装，通过 Git 克隆仓库
  vim.fn.system({
    "git",
    "clone",
    "--filter=blob:none",         -- 优化克隆速度（不下载冗余文件）
    "https://github.com/folke/lazy.nvim.git",
    "--branch=stable",            -- 使用稳定分支
    lazypath,                     -- 克隆到指定路径
  })
end

-- 将 lazy.nvim 的路径添加到 Neovim 的运行时路径（rtp）开头
-- 确保 Neovim 能优先加载此插件管理器
vim.opt.rtp:prepend(lazypath)

用 <leader>ee（我的配置中 键是空格）打开文件管理器。

添加以下配置代码：

return {
  "lewis6991/gitsigns.nvim", -- 插件名称
  event = { "BufReadPre", "BufNewFile" }, -- 在文件读取前或新建文件时加载
  opts = { -- 插件配置选项
    on_attach = function(bufnr) -- 绑定到缓冲区时的配置
      local gs = package.loaded.gitsigns -- 获取插件API

      -- 辅助函数：创建快捷键映射
      local function map(mode, l, r, desc)
        vim.keymap.set(mode, l, r, { buffer = bufnr, desc = desc })
      end

      ------------------
      -- 导航快捷键 --
      ------------------
      map("n", "]h", gs.next_hunk, "跳转到下一个变更块 Next Hunk") -- 类似 ]c 行为
      map("n", "[h", gs.prev_hunk, "跳转到上一个变更块 Reset hunk")

      ------------------
      -- 操作快捷键 --
      ------------------
      -- 普通模式操作
      map("n", "<leader>hs", gs.stage_hunk, "暂存当前变更块 Stage hunk") -- git add 当前块
      map("n", "<leader>hr", gs.reset_hunk, "重置当前变更块 Reset hunk") -- git reset 当前块
      map("n", "<leader>hS", gs.stage_buffer, "暂存整个文件 Stage buffer") -- git add 整个文件
      map("n", "<leader>hR", gs.reset_buffer, "重置整个文件 Reset buffer") -- git reset 整个文件
      map("n", "<leader>hu", gs.undo_stage_hunk, "撤销暂存操作 Undo stage hunk") -- 回退暂存操作

      -- 可视模式操作
      map("v", "<leader>hs", function() -- 暂存选中区域
        gs.stage_hunk({ vim.fn.line("."), vim.fn.line("v") }) -- 获取选中行范围
      end, "暂存选中区域 Stage hunk")
      map("v", "<leader>hr", function() -- 重置选中区域
        gs.reset_hunk({ vim.fn.line("."), vim.fn.line("v") })
      end, "重置选中区域 Reset hunk")

      ------------------
      -- 查看与对比 --
      ------------------
      map("n", "<leader>hp", gs.preview_hunk, "预览变更差异 Preview hunk") -- 浮动窗口显示变更
      map("n", "<leader>hb", function() -- 显示详细提交信息
        gs.blame_line({ full = true }) -- 显示完整blame信息
      end, "查看当前行提交记录 Blame line")
      map("n", "<leader>hB", gs.toggle_current_line_blame, "切换行级提交记录显示 Toggle line blame") -- 切换blame显示
      map("n", "<leader>hd", gs.diffthis, "对比工作区与暂存区 Diff this") -- git diff
      map("n", "<leader>hD", function() -- 对比工作区与最新提交
        gs.diffthis("~") -- 对比HEAD~1
      end, "对比工作区与最新提交 Diff this ~")

      ------------------
      -- 文本对象 --
      ------------------
      -- 通过 ih 选择变更块（操作符模式/可视模式）
      map({ "o", "x" }, "ih", ":<C-U>Gitsigns select_hunk<CR>", "选择变更块区域 Gitsigns select hunk")
    end,
  },
}
