Vim Essentials 备忘单和指南

发表于 2025-04-03 分类于 Vim

来源：https://www.josean.com/posts/vim-essentials-cheatsheet

这是我的 Vim 速查表，里面有所有最重要的命令！你可以观看我的 YouTube 视频，了解几乎所有这些命令的工作原理以及我如何记住它们的完整指南.

Vim 模式切换

快捷键描述
i进入插入模式（光标位置）
a在光标后方进入插入模式（理解为追加）
A在行尾进入插入模式
o在下方新建空行并进入插入模式
O在上方新建空行并进入插入模式
v进入可视化模式（字符选择）
Ctrl-v进入块可视化模式（列选择）
:进入命令行模式
R进入替换模式（覆盖字符，行尾转为插入）
ESC从任何模式退回普通模式

说明

  1. 块可视化模式（Ctrl-v）:

    • 支持多行列编辑，如用 I 在选中列前批量插入
    • 冲突解决：若与系统粘贴快捷键冲突，可在 .vimrc 中重映射

  2. 替换模式（R）:

    • 覆盖字符时，按 Backspace 可恢复原内容
    • 行尾自动转为普通插入模式

  3. 快速定位插入:

    • A = $i（行尾插入的快捷操作）
    • o/O 新建行时会继承当前缩进

文件保存与退出

命令核心功能
:w保存文件但不退出编辑器
:wa保存所有打开的文件但不退出编辑器
:q退出编辑器（若存在未保存更改会阻止退出）
:q!强制退出编辑器并放弃所有未保存更改
:wq/:x保存当前文件并退出编辑器（二者等效）
:wqa保存所有打开的文件并退出编辑器

  • 区别提醒：

    • :x 和 :wq 的细微差异：当文件无修改时，:x 不会更新文件时间戳
    • :qa! 可强制关闭所有分屏窗口（即使有未保存的更改）

  • 组合技巧：

    • :w !sudo tee % 无保存权限时，用 sudo 强制保存当前文件
    • :w newfile.txt 另存为新文件
    • ZZ（普通模式下大写连续按两次 Z）等效于 :wq

光标移动

方向键控制

命令核心功能
h向左移动光标（移动至行首最左端）
j向下移动光标（按键形状暗示向下箭头方向）
k向上移动光标
l向右移动光标（移动至行尾最右端）

说明

  • 效率技巧：

    • 组合数字实现快速移动：5j = 向下跳 5 行，3h = 向左跳 3 字符
    • w/b 按单词移动，比逐字符更高效
    • 0 跳到行首，$ 跳到行尾（与 A 插入模式形成动线组合）

  • 历史背景：
    hjkl 方向键源自早期终端 ADM-3A 的物理键位布局，成为 Vim 的标志性设计

行内光标移动

命令核心功能
$移动到行尾
0移动到行首（包括缩进空格）
^移动到行内第一个非空白字符处
fx正向查找字符 x，光标跳转到下一个匹配位置
Fx反向查找字符 x，光标跳转到上一个匹配位置
tx正向查找字符 x，光标跳转到匹配字符前一位
Tx反向查找字符 x，光标跳转到匹配字符后一位
;重复上一次 f/F/t/T 的正向查找
,重复上一次 f/F/t/T 的反向查找

说明

  • 高频组合技巧：

    • d$ = 删除至行尾，等效于 D
    • ct) = 从光标处删除到右括号前，并进入插入模式（change to )）
    • 2f. = 连续查找第二个出现的 . 符号

  • 精准定位：

    • 0 与 ^ 的区别：0 始终到行首第一列，^ 到第一个非空白字符（跳过缩进）
    • t 系列命令适合精确修改符号边界内容（如 dt" 删除到引号前）

  • 效率对比：

    • 用 f/t 查找比逐字符移动快 5 倍以上（例如 f. 直接跳转到句尾）
    • ; 和 , 可快速遍历同一字符的多个匹配位置

单词级移动

核心概念定义

  • 单词（word）：
    • 由字母/数字/下划线组成的连续字符 或 其他符号组成的连续字符（以空白分隔）
    • 用 :h word 查看官方定义
  • 大词（WORD）：
    • 任意非空白字符组成的连续字符（包括符号混合，如 abc-123! 视为一个 WORD）
    • 用 :h WORD 查看官方定义
命令核心功能
w正向跳转到下一个单词开头（字母/数字/下划线 或 符号块）
W正向跳转到下一个大词开头（忽略符号类型差异）
b反向跳转到上一个单词开头
B反向跳转到上一个大词开头
e正向跳转到当前单词结尾
E正向跳转到当前大词结尾
ge反向跳转到上一个单词结尾
gE反向跳转到上一个大词结尾

说明

行为差异示例
  • 文本 foo-bar_baz,test!：
    • w 将停于：foo → - → bar_baz → , → test → !
    • W 将停于：foo-bar_baz,test!（整个作为 1 个 WORD）

跳转列表导航

某些将光标移开几行的 vim 动作会将条目添加到 跳转列表 . 您可以使用 :jump 显示 跳转列表.

  • 记录机制：特定的大范围光标移动操作会自动记录跳转位置
  • 查看方式：输入 :jump 查看完整跳转历史
  • 容量限制：默认记录 100 条跳转记录（可通过 set jumpoptions=stack 修改）

常用的将条目添加到跳转列表的命令：G、gg、[number]G、/、?、n、N、%、(、)、{、}、:s、L、M、H. 在同一个窗口中导航到不同的文件/缓冲区也是可行的

重要：[number]j 和 [number]k 不会将条目添加到跳转列表.

快捷键核心功能场景用途
Ctrl-O返回跳转列表中的上一个位置回溯代码审查路径
Ctrl-I跳转到跳转列表中的下一个位置恢复前进导航

文本对象操作 🚀

我个人很喜欢使用这个功能！
您可以使用 Vim 文本对象对该对象执行操作符，或者使用可视模式选择它（使用 v 进入可视模式）.

要使用文本对象，请将光标放在文本对象内的任意位置，然后键入 {operator}，后跟 {text object}，以在该对象上执行运算符.

文本对象 (Text Objects)

通过语义化边界快速操作代码块/文本单元，无需精确移动光标
黄金法则：

  • i（inside）：操作内容本体（不包含边界符号）
  • a（around）：操作完整单元（包含边界符号）

符号边界对象

对象命令描述操作示例
a"双引号及内容da" 删除引号及字符串

i'单引号内部内容di' 删除引号内文本
